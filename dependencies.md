# Required dependencies in order to work on Neon

## Basic requirements (compiling/executing)

- gcc/clang compiler with binutils tools like ld and as
- make
- git

## Running the tests

- valgrind

## Run a deploy task

- A Linux and a Windows installation
- A working Inno Setup installation (on Windows)
- A working Linux Package Maker installation (on Linux)
- python3 (on Linux)
- bash (on Linux)
